Guide

使用说明

从注册到连接的完整流程，按以下四个步骤依次操作即可。每一步只包含必要动作，无需额外配置。

注册账户并选择套餐

访问速蛙云(fasterfrog)官网注册账户，根据每月流量需求与同时在线设备数量，在基础版、旗舰版、团队版中选择一档完成订阅。按年付费可享折合优惠。

获取订阅链接

登录用户中心，在订阅管理页面复制专属订阅链接。该链接包含全部节点信息，请妥善保管，不要分享给账户授权范围之外的人员。

导入客户端

在所用设备上安装对应的机场客户端，选择"从订阅链接导入"，粘贴上一步复制的链接，客户端将自动拉取节点列表。具体操作见下方客户端说明。

选择节点并连接

在节点列表中选择一个节点，开启系统代理或全局连接。流媒体观看建议选择标注解锁的节点；游戏场景下旗舰版用户可优先选择 IPLC 专线节点。

Clients

客户端说明

速蛙云(fasterfrog)通过标准订阅链接适配各平台主流客户端。以下按设备类型说明配置方式，具体客户端版本请从各应用官方渠道获取。

桌面端

Windows 与 macOS 设备可使用支持订阅导入的主流代理客户端。安装后在订阅管理中添加订阅链接，更新订阅即可同步节点列表，随后选择节点并启用系统代理。

移动端

iOS 与 Android 设备可使用各自平台上支持订阅功能的客户端。通过剪贴板导入订阅链接，客户端会自动解析节点。移动端建议开启按需连接，以节省流量与电量。

多设备管理

同一账户下的设备共享套餐流量，同时在线数量受套餐限制：基础版 3 台、旗舰版 5 台、团队版 20 台。超出限制的设备将被排队或断开，可在用户中心管理已登录设备。

FAQ

常见问题

以下问题按出现频率整理，涵盖套餐选择、流量计算、设备限制与订阅安全。如未覆盖你的问题，可通过工单渠道咨询。

三档套餐应该如何选择？

以个人使用强度为判断标准：每月流量需求在 100GB 以内、设备不超过 3 台，选择基础版即可；需要流媒体全节点解锁或游戏专线加速，选择旗舰版；多人共享或企业场景，选择团队版。

流量是如何计算和重置的？

套餐流量按自然月计算，每月固定额度：基础版 100GB、旗舰版 300GB、团队版 1000GB。流量在结算周期开始时重置，当月未用完的流量不结转至次月。

同时在线设备数超限会怎样？

当同时在线设备数达到套餐上限时，新接入的设备将无法建立连接，或按规则断开最早接入的会话。可在用户中心查看并移除不再使用的设备。

旗舰版的 IPLC 专线适合什么场景？

IPLC 专线节点针对游戏加速做了优化，适合对延迟和稳定性要求较高的在线游戏场景。日常网页浏览和普通视频观看使用常规节点即可，不必占用专线资源。

订阅链接泄露了怎么办？

订阅链接等同于账户凭证。如怀疑泄露，请立即在用户中心重置订阅链接，旧链接随即失效，然后在各设备客户端中更新为新链接。

按月付和按年付有什么区别？

套餐权益完全相同，区别仅在计费方式。按年付折合为：基础版 ¥150/年、旗舰版 ¥350/年、团队版 ¥850/年，相比按月付各节省约两个月费用。
